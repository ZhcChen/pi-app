# desktop 主界面重设计计划

- 任务：基于 Codex 风格参考图重设计 `desktop` 主界面
- 状态：已完成
- 负责人：Pi
- 日期：2026-07-26

## 目标

将 `desktop` 模块当前的占位式控制台壳界面，重设计为更接近桌面 AI coding client 使用习惯的工作台：包含左侧导航栏、项目区、中央空态引导区、建议卡片和底部命令输入器。

## 范围

这次会改动：

- 新增 `docs/plans/2026-07-26-desktop-shell-redesign.md`
- 重写 `desktop/lib/main.dart` 的主界面布局与视觉样式
- 调整 `desktop/test/widget_test.dart`，使测试对齐新的桌面壳结构

## 非目标

- 不接入真实 `pi agent` 运行时
- 不实现会话发送、项目切换、插件系统或 PR 工作流
- 不做平台原生标题栏深度定制

## 影响区域

- 文件：`desktop/lib/main.dart`、`desktop/test/widget_test.dart`、`docs/plans/2026-07-26-desktop-shell-redesign.md`
- 模块：`desktop`
- 接口 / 约束：Flutter 桌面端；深色工作台风格；优先对齐 coding client 使用习惯

## 实现思路

1. 按参考图拆成三层：左侧导航、中央主工作区、底部输入器。
2. 保留当前项目语义，但把展示方式调整成更接近 coding client 的桌面壳。
3. 通过假数据补齐典型状态块，让界面在无真实后端时也具备完整的桌面产品形态。

## 阶段拆分

### 阶段 1

- 目标：完成主布局重构
- 边界：只处理 Flutter 端布局、配色、间距和静态内容
- 验收重点：整体结构与参考图一致，桌面视图稳定

### 阶段 2

- 目标：补齐空态、建议卡、输入器和侧栏项目层级
- 边界：仅做静态交互壳
- 验收重点：主要交互区块完整，可作为后续功能接入载体
