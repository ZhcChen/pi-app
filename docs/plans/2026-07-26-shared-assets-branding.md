# 公共资源与品牌素材初始化计划

- 任务：创建根目录公共资源目录并设计 Pi 风格 logo
- 状态：已完成
- 负责人：Pi
- 日期：2026-07-26

## 目标

在仓库根目录建立一个用于存放公共资源的目录，并产出一套围绕 `Pi` 语义、采用黑白极简风格的基础 logo 资产，供后续桌面客户端和其他模块复用。

## 范围

这次会改动：

- 新增 `docs/plans/2026-07-26-shared-assets-branding.md`
- 新增根目录公共资源目录及其说明文件
- 新增黑白 logo SVG 资产（至少包含 icon 与可读性更高的 lockup 版本）

## 非目标

- 不修改桌面端应用内的界面接入
- 不生成多尺寸导出图（png/icns/ico）
- 不定义完整品牌规范手册

## 影响区域

- 文件：`docs/plans/2026-07-26-shared-assets-branding.md`、`assets/**`
- 模块：仓库根目录公共资源
- 接口 / 约束：资产优先使用 SVG；风格保持黑白、简洁、可跨模块复用

## 实现思路

1. 在根目录建立统一的公共资源目录，避免后续模块各自散落素材。
2. 设计一套围绕 `Pi` 与本地 agent 客户端语义的单色 logo，优先保证在浅色和深色背景上的可用性。
3. 补充简短说明，记录文件用途、推荐用法和后续扩展入口。

## 阶段拆分

### 阶段 1

- 目标：建立公共资源目录与说明结构
- 边界：只做当前 branding 所需的最小结构
- 验收重点：目录命名清晰、资源分类明确

### 阶段 2

- 目标：产出可复用的 logo 资产
- 边界：只提供 SVG 基础稿，不延伸到应用图标打包
- 验收重点：图形风格统一，黑白场景可直接使用

## 执行单元

### 单元 1

- 所属阶段：阶段 1
- 目标：创建根目录资源目录与说明
- 涉及文件 / 模块：`assets/README.md`、`assets/branding/**`
- 前置依赖：无
- 验证方式：检查目录与说明内容
- 完成标准：目录用途明确，可承载后续共享素材

### 单元 2

- 所属阶段：阶段 2
- 目标：设计 icon 版 logo
- 涉及文件 / 模块：`assets/branding/pi-mark.svg`
- 前置依赖：单元 1 完成
- 验证方式：检查 SVG 结构与可读性
- 完成标准：图形能独立表达品牌语义

### 单元 3

- 所属阶段：阶段 2
- 目标：设计 lockup 与反白版本
- 涉及文件 / 模块：`assets/branding/pi-logo.svg`、`assets/branding/pi-logo-inverse.svg`
- 前置依赖：单元 2 完成
- 验证方式：检查文件内容与说明文档
- 完成标准：浅深背景下均有可用版本
